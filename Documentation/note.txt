용접 중간에 정지시 배출 처리
용접 시퀀스상에 프로그램 실행 전이면 2D 검사부터 다시 시작

재시작 조건 정리 (버퍼위치 재시작 방식을 제품 상태에 따라 분기가 어려움)
	WS: BK:없음, BW:용접전, AW:용접후, ER:배출품
	VS: BK:없음, BV:검사전, AV:검사후, ER:배출품
	TR: BK:없음, EX:있음
	!!! 각 상태는 유닛 시퀀스 단위로 쪼개기 불가능
		Ex) 언로딩시 언로딩 완료되지 않은 시점(픽업 후, 커버 닫기전)에 제품 위치가 변경
	!!! WS의 충돌가능 시퀀스는 Unloading, VS의 충돌가능 시퀀스는 Loading, Ready, Vision
//-----------------------------------------------//
	TR:BK(제품 없음)
		- 그리퍼 오픈
		- 피커 업

	TR:EX(제품 있음)
		- 그리퍼 클로즈
		- 피커 업

//-----------------------------------------------//
	WS:BK(제품 없음)
		- 로딩

	WS:AW(용접전 제품)
		- 레디(검사)

	WS:BW(용접후 제품)
		- 대기(언로딩시 충돌 우려 있으므로 먼저 대기위치로)
		- 최적화시 VS 상태와 WS의 모터 현재 위치로 판단

	WS:ER(배출 제품)
		- 배출

	BK -> BW : Place 후 제품 감지 완료시
	BW -> AW : 용접 모션 완료 후
	AW -> BK : Pick 후 제품 감지 완료시
	ER : 2D 비젼 실패
//-----------------------------------------------//	
	VS:BK(제품 없음)
		- 로딩전 대기(로딩시 출돌 우려 있으므로 대기 위치로 이동)

	VS:BV(검사전 제품)
		- 로딩후 대기(검사전 충돌 우려 있으므로 대기 위치로 이동)

	VS:AV(검사후 제품)
		- 언로딩 

	VS:ER(배출 제품)
		- 배출
	BK -> BV : Place 후 제품 감지 완료시
	BV -> AV : 비젼 모션 완료 후 3D 검사 성공
	AV -> BK : Pick 후 제품 감지 완료시
	ER : 3D 비젼 실패

//-----------------------------------------------//
	전체 시퀀스 시작 순서
		1. TR 준비
		2. VS 시작
		3. WS 시작

//-----------------------------------------------//
	용접 스테이지 시퀀스 정리
		1. 로딩
		2. 비젼
		3. 용접
		4. 대기
		5. 언로딩
		!!! 언로딩 완료 후 다시 로딩으로 이송
		!!! 1 Cycle 명령시 대기 위치로 이동 후 종료
		!!! 로딩과 대기는 위치값은 거의 동일하나 유닛 시퀀스상
			단순 이동과 모션 실행의 차이가 있어 편의상 나눔

//-----------------------------------------------//
	비젼 스테이지 시퀀스 정리
		1. 로딩

		!!! 언로딩 완료 후 다시 로딩으로 이송

		!!! 로딩과 대기는 위치값은 거의 동일하나 유닛 시퀀스상
